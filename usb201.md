# USB-201 Linux Setup

## Dependencies

### 1. System packages

```bash
sudo apt-get install -y gcc g++ make libusb-1.0-0-dev autoconf automake libtool
```

### 2. libuldaq (native shared library)

`USB201.py` uses the `uldaq` Python package, which requires `libuldaq.so` from MCC's
UL for Linux project — separate from the older `mcc-libusb` / `MCC_Linux_Drivers` repo.

```bash
git clone https://github.com/mccdaq/uldaq.git /tmp/uldaq
cd /tmp/uldaq
autoreconf -i
./configure
make
sudo make install
sudo ldconfig
```

Verify:

```bash
ldconfig -p | grep uldaq
```

### 3. Python package

```bash
pip install uldaq
```

### 4. udev rules (non-root USB access)

The `MCC_Linux_Drivers` repo already contains the needed rules file:

```bash
sudo cp /home/anders/Code/python/equipment/MCC_Linux_Drivers/61-mcc.rules /etc/udev/rules.d/
sudo udevadm control --reload
sudo udevadm trigger
```

## API fix — AiScanFlag → AInFlag

The `uldaq` Python package renamed `AiScanFlag` to `AInFlag` in newer versions.
`USB201.py` has already been patched to use `AInFlag`.

## Verify

```bash
python USB201.py
```

Expected output shows the device found by serial number and reads all 8 analog channels.
Floating (unconnected) inputs will read a small nonzero voltage (~1.7 V) — this is normal.
Short an input pin to AGND on the terminal block to verify a clean 0 V read.
